# Contributing

Thanks for your interest in improving the Multi-Agent AI Workflow Platform! Contributions of all sizes are welcome — bug fixes, new tools, docs, tests, or entirely new agent capabilities.

## Getting started

1. Fork the repo and clone your fork.
2. Follow the backend/frontend setup steps in the [README](README.md).
3. Create a branch for your change: `git checkout -b my-feature`.

## Development

- Backend: Python 3.11+, FastAPI. Run tests with `pytest tests/ -v` from `backend/`.
- Frontend: Node.js 18+, React/TypeScript/Vite. Run `npm run dev` from `frontend/`.
- Keep changes focused — smaller PRs are easier to review and merge.

## Submitting changes

1. Make sure existing tests pass and add tests for new behavior where practical.
2. Write a clear commit message describing the change and why it's needed.
3. Open a pull request describing what changed and how you tested it.

## Reporting issues

Use GitHub Issues for bugs and feature requests. Include repro steps, expected vs. actual behavior, and relevant logs/tracebacks when reporting bugs.

## Code of conduct

Be respectful and constructive. Assume good intent, and keep discussion focused on the code and the problem being solved.
